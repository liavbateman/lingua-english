# Lingua

An English-learning web app for Hebrew speakers: vocabulary, useful sentences and grammar rules in three levels, with a Hebrew (right-to-left) interface and an English switch.

Built for iPhone: open the link in Safari and choose **Share → Add to Home Screen** to use it full screen and offline.

- `index.html`, `css/`, `js/app.js` — the app
- `js/data.js`, `js/content-*.js` — words and sentences
- `js/grammar.js`, `js/content-*.js` — grammar rules
- `js/i18n.js` — interface texts in Hebrew and English
- `node scripts/validate-content.mjs` — checks all content for mistakes
